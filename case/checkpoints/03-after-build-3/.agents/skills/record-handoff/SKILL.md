1. Update docs/evidence.md with session, agent, skills used, task, actual check results, stop reason, and human decision. Preserve earlier records instead of replacing unrelated work.
2. Record remote MCP server/tool calls, source URLs, claims checked, and the resulting decision. Label unavailable lookups blocked and distinguish documentation from runtime evidence.
3. Read the handoff when resuming and recheck stale assumptions. Clearly identify supplied/recovery work. Never record secrets or invented results.
