---

1. Follow the actual local application through browser/direct API response, correlation ID, prepared server log, and persisted activity. These are ordinary development tools, not MCP servers.
2. Use Microsoft Learn MCP to verify an applicable logging, persistence, or transaction concept. Do not fabricate a trace or activity record for rejection.
3. Separate application observations from Codex execution evidence. Keep raw descriptions/credentials out of logs and report unresolved gaps.
